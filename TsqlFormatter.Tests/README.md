# TsqlFormatter.Tests

Регрессионные тесты форматтера. Каждый кейс — пара (вход, ожидаемый выход),
прогоняется через реальный конвейер Lexer → Parser → FormatterEngine.

## Запуск

    run-tests.bat                 — все тесты
    run-tests.bat --rule 2.6      — только правило 2.6
    run-tests.bat -v              — печатать вывод каждого пройденного теста

Или напрямую:

    dotnet run -c Release --project TsqlFormatter.Tests

## Как добавить тест

Открыть `TestCases.cs`, добавить в список `All()`:

    new TestCase {
        Rule = "2.X", Name = "краткое описание",
        Input    = "...исходный SQL...",
        Expected = "...ожидаемый отформатированный вывод...",
    },

Табы в Expected — реальные символы `\t`. Сравнение игнорирует хвостовые
пробелы в строках и переводы строк по краям, но учитывает отступы.

## Вывод

При падении теста печатается построчный diff: зелёным — ожидаемое,
красным — фактическое. Табы показаны как `→`.
